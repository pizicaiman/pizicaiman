# 朋友圈文案索引

本目录基于 [slogans/](../slogans/) 的 12 个营销口号，派生出对应的朋友圈短文案，适合发在个人朋友圈、客户群、私域触达场景。

每篇文案结构统一：朋友圈正文（150 字以内，口语化，像真人发朋友圈）+ 配图建议 + 互动引导。不含价格、不含 emoji，便于直接复制发布。

## 使用建议

- **日常触达**：直接复制"朋友圈正文"发布，配图按建议准备。
- **私聊跟进**：把"互动引导"那句作为私聊开场白，承接朋友圈评论。
- **组合发送**：一篇朋友圈文案 + 对应 [slogans/](../slogans/) 口号 + [deals/](../deals/) 小单品，构成"认知—兴趣—试单"路径。
- **节奏建议**：每周 2-3 篇，避免连发同主题，交叉覆盖底座、流水线、可观测、安全等方向。
