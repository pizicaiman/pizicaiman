# ArgoCD GitOps 部署落地 · 小合作单品

## 一句话价值
把"部署"变成 Git 里的一次提交，可追溯、可回滚。

## 适用场景
- 部署仍靠 kubectl 手工或脚本，状态不可见。
- 多环境配置漂移，"我这能跑"成常态。
- 希望引入 GitOps 但不知如何起步。

## 交付内容
- ArgoCD 部署与集群接入。
- Git 仓库结构与应用编排规范（Kustomize/Helm）。
- 多环境配置管理与同步策略。
- 回滚机制与同步健康检查。
- 基础培训 + 《GitOps 使用手册》。

## 交付方式
- 远程协同，按 1-2 个应用示范落地。
- 输出可用 ArgoCD 配置 + 规范文档。

## 交付边界（不包含）
- 不含 CI 流水线搭建（见 02）。
- 不含全量应用迁移（可另议）。
- 不含生产故障响应。

## 配套能力
DevOps 与持续交付、自动化与效率工程。

## 适配
- 口号：02-devops-pipeline（让每一次提交，都安全地走向生产）
- 方案 B：DevOps 流水线与持续交付方案

## 客户常问 3 问（FAQ）

**Q1：这个包含 CI 流水线搭建和全量应用迁移吗？**
不包含。本单品以 1-2 个应用示范落地 GitOps 链路。CI 流水线搭建见 02，全量应用迁移可另议。

**Q2：需要我们配合什么？多久能完成？**
需提供 Git 仓库与目标集群访问，确认应用编排方式（Kustomize/Helm）。通常 2-3 周完成示范，按项目计费。

**Q3：做完之后部署就不会出问题吗？**
能保证 GitOps 链路可用、可回滚、状态可观测，但部署成功率仍依赖应用本身配置正确性。后续可另购故障响应。
